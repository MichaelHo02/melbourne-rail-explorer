# Melbourne rolling-stock asset research

Checked 19 September 2026. This is a shortlist, not an acquisition or a licence clearance. No asset was bought, downloaded, extracted from a game, or added to the repository.

## Best verified Blender-compatible candidate

[Melbourne Metro Xtrapolis 100 — at3d, CGTrader](https://www.cgtrader.com/3d-models/vehicle/train/melbourne-metro-xtrapolis-100)

- Primary product page opened successfully. Native `.blend` (93.8 MB) and `.obj` exchange files (31.9 MB) are listed; Blender/Cycles 3 is the stated renderer.
- Described as a low-poly Melbourne X'Trapolis 100 replica with non-overlapping UVs and 4K TGA textures. **No interior** is included, so it cannot supply the driving cab by itself. Plugins Used is also flagged; exact dependencies need checking with the seller.
- Product page labels it **Royalty Free License**. It is a marketplace acquisition candidate; the extracted product page did not expose a current purchase price, so no price is claimed here.
- Best evidenced existing asset for Blender integration, provided an X'Trapolis is acceptable instead of the HCMT reference selected for this game. Materials, door separation, mesh quality and web performance remain untested because the actual file was not obtained.

[CGTrader's current terms](https://www.cgtrader.com/pages/terms-and-conditions) limit distribution to an incorporated product, describe game usage inside a proprietary format, and prohibit standalone redistribution. A public raw `.glb` or `.blend` in this repository should therefore **not** be assumed permitted by the Royalty Free label. Confirm browser-game delivery terms with the seller before adopting this asset.

## Verified alternative with a restrictive listing

[Alstom Xtrapolis 100 — torytrae, TurboSquid](https://www.turbosquid.com/3d-models/alstom-xtrapolis-100-australian-electric-passenger-train-metro-melbourne-3d-2429337)

- Primary listing displays **$20** (dollar denomination as displayed), `.blend` for Blender 2.78, `.fbx`, `.obj`, 3ds Max and Wings3D formats.
- Textures, materials and UVs are listed. The mesh has 139,285 polygons / 148,412 vertices and 93 objects. Despite its “low poly” description it warrants reduction and materials work for a browser game.
- **Editorial Uses Only** is explicit on the page. This is not a default game-asset recommendation under its displayed terms; separate permission would be needed before treating it as suitable for this project.

## Siemens Nexas: promising lead, not cleared for import

A creator published separate detailed SketchUp components:

- [Front/body without wheels](https://3dwarehouse.sketchup.com/model/b78ae81b-c136-435e-8b1e-eff95a5c66f8/Siemens-Nexas-Train-Front-no-wheels)
- [Front wheels](https://3dwarehouse.sketchup.com/model/d79ed44c-3a7e-4d2a-a324-8b8067cc7f58/Siemens-Nexas-Train-Front-wheels)
- [Middle body](https://3dwarehouse.sketchup.com/model/4f1ee7d4-6020-4f1d-bcb1-adc23455722f/Siemens-Nexas-Train-middle-no-wheels)
- [Middle wheels](https://3dwarehouse.sketchup.com/model/01f081a9-06f0-4fa8-a141-2a00d219334f/Siemens-Nexas-Train-middle-wheels)
- [Seats](https://3dwarehouse.sketchup.com/model/585bb914-8997-475d-a44d-ac26547c7156/Siemens-Nexas-Train-seats)

The primary 3D Warehouse asset pages were inaccessible to the web reader. Current file formats, download access, price and licensing could not be verified there. The [creator's original announcement](https://www.reddit.com/r/melbourne/comments/pji6qh) confirms these links and SketchUp authorship. Its comments offer credited animation use but express uncertainty about rights, so they do not establish an unambiguous game redistribution licence. Treat these as conversion/permission leads, not acquired Blender-ready files.

[voxellation's Sketchfab profile](https://sketchfab.com/continentialvoxels) also lists a downloadable “Siemens Nexas lead” among numerous voxel trains. Search indexing exposed this profile, but direct page access failed and the individual asset page, format and licence were not verified. It is a lower-priority lead for a realism-focused game.

## HCMT and other sources

No downloadable HCMT asset with verified Blender-compatible formats and game-use terms was found in this bounded search. This is not evidence that none exists. [Denova's official HCMT familiarisation case study](https://denovasolve.com/metro-trains-melbourne-new-train-familiarisation-app/) describes a detailed model made from Metro/manufacturer design files, with full cab and exterior, but offers no public model download or reusable asset licence.

Searches also surfaced Brimbank Models' HCMT printing parts (STL) and Steam Workshop trains. Neither is an evidenced licensed game-model substitute: printing geometry requires different preparation, and Workshop access alone does not grant reuse in an independent game.

## Recommended decision

For an existing asset, evaluate the at3d X'Trapolis with the seller for browser-game rights and a cab solution. The supplied photographic reference shows an **HCMT**. The implemented train is an original Blender-authored HCMT recreation guided by that image and official project references. Do not describe any of these unacquired files as integrated, verified game-ready, or freely redistributable.
