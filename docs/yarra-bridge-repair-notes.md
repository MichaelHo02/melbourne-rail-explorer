## Historical deck reconstruction study

`scripts/yarra-bridge-download-parallel.py` downloads only OBJ compressed entries from official municipal ZIPs using eight concurrent byte ranges, then verifies uncompressed byte count, ZIP CRC32 and SHA256 before exposing usable files. Initial C4-31/32 guesses were rejected. The official tile index later established C4-33/D4-03 for Queens, D4-02 for Kings, and D4-01/D4-07 for Spencer; original C4-28/34 capture does not cover those bridges.

`scripts/yarra-bridge-capture-evidence.py` extracts upward historical triangle centres inside original footprint insets, with one-metre median heights. `scripts/yarra-bridge-prepare-decks.py` requires nonempty source coverage for every bridge, unions Kings sections and fits local24-neighbour lower-quartile heights to5m triangulation. This suppresses elevated cars/railings but can retain other scan artefacts; visual profile acceptance required. `scripts/blender/yarra-bridge-captured-decks.py` installs recoverable unified decks and reconciles rails/structure/carriageway heights. `YARRA_BRIDGE_CAPTURED_DECKS=1` enables this optional study stage only after source data exists.

**Final capture study outcome: no deck replacement accepted.** Official tile polygon intersections establish Kings100%D4-02; Spencer72.8%D4-01/27.2%D4-07; Queens87.3%C4-33/12.7%D4-03. Correct D4-02/D4-01 OBJ entries fully verified. Queens4/Spencer14 above3m cells are insufficient. Kings has620+1009 section cells, but their spatial strips do not constrain a complete deck: a two-axis fit extrapolates below water; a longitudinal-only fit predicts−1.66…5.68m with4.3% slope. Local-neighbour trial visibly creates patchy/intersecting road/cap triangles. Both rejected. The generated unified-decks JSON deliberately contains no accepted parts, and installer refuses it.

Opt-in `YARRA_BRIDGE_ISOLATE_KINGS=1` instead isolates the ambiguous11m upper generic envelope, its overlapping carriageway and12 cap triangles recoverably. It retains the existing5m lower envelope; this is a diagnostic clean single-deck appearance, not newly verified elevation. Latest western preview uses this isolation plus authored neutral deck finishes and source-family structure. Further precise bridge ground/profile work remains open; no claim of fully accurate bridge construction.
