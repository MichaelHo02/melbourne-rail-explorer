Open city-observatory.blend in Blender, select the named camera and press Num 0. Latest native preview was shown in Rendered shading. Saved viewport mode can vary on reopening; choose Rendered shading to see scene lighting. Preserve unsaved work before reloading. The Mac must be unlocked to refresh the live Blender window.
